# Iconos del sistema

Estructura centralizada para pegar SVGs manualmente.

Regla: pega el contenido completo del icono dentro del archivo .svg correspondiente.

Categorias:
- navigation: sidebar y navegacion general
- modules: iconos de modulos de negocio
- status: estados visuales (activo, proximo, error, etc.)
- actions: acciones comunes (buscar, filtrar, editar, etc.)
- system: infraestructura/usuario/sistema
